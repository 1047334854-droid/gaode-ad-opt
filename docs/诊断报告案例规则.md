## 一、报告总体结构（6大板块）

报告由6个固定板块组成，严格按以下顺序排列，不可增删或调换：

| 序号 | 板块名称 | 核心作用 | 数据来源 |
|------|----------|---------|----------|
| 头部 | 门店名称+副标题+地址+日期+对比范围 | 封面/品牌识别 | 用户输入 |
| 一 | 经营数据现状 | 量化差距，建立问题意识 | 门店经营数据截图 |
| 二 | 页面诊断（五要素×四层漏斗） | 定位页面问题，逐要素诊断 | 7类截图中的5张详情截图 |
| 三 | 周边合作门店对比 | 具象化竞争差距 | 搜索列表页截图+手动填写 |
| 四 | 合作案例（合作前后效果对比） | 建立合作信心 | 合作案例截图 |
| 五 | 优化方案（4条） | 给出行动路径 | 基于诊断数据自动生成 |
| 六 | 保守目标 | 设定预期，推动决策 | 基于数据自动计算 |

## 三、经营数据要求（4项核心数据×3组）

### 3.1 本店数据（必填，4项缺一不可）

| 指标 | 说明 | 校验规则 |
|------|------|---------|
| 曝光量 | 本店月度曝光量 | 必须 > 0 |
| 点击量 | 本店月度点击量 | 必须 > 0 |
| 导航量 | 本店月度导航量 | 必须 > 0 |
| 来电量 | 本店月度来电量 | 必须 > 0 |

**强制校验：** 4项数据必须全部收集完整（>0），否则不允许生成报告。

### 3.2 周边均值 & 同城均值（选填，无则显示"—"）

每项指标均有3组数据：本店、周边均值、同城均值。

### 3.3 自动计算的转化率（3项）

| 转化率 | 计算公式 |
|--------|---------|
| 曝光→点击率 | 点击量 ÷ 曝光量 × 100% |
| 点击→导航率 | 导航量 ÷ 点击量 × 100% |
| 点击→来电率 | 来电量 ÷ 点击量 × 100% |

### 3.4 差距计算规则

| 指标类型 | 差距标签文案 | 标签样式 |
|----------|-------------|---------|
| 绝对值（曝光/点击/导航/来电） | "仅周边X%" = 本店÷周边×100% | 红色（`.gap-tag.bad`） |
| 转化率高于周边 | "高于周边" | 绿色（`.gap-tag.good`） |
| 转化率低于周边 | "略低"/"低于周边" | 红色（`.gap-tag.bad`） |

### 3.5 一句话结论规则

根据数据表现，从以下模板中选择或生成：

| 数据特征 | 结论文案 |
|----------|---------|
| 绝对值低但转化率高 | "问题在前面——**没人看到**、**看到了不想点**" |
| 绝对值和转化率都低 | "页面和流量都需要优化" |
| 绝对值还行但转化率低 | "流量有基础，但页面留不住人" |

#### 五个要素详细内容

**要素一：头图/封面 → 影响「点击率」**
- 截图：搜索列表页（在搜索结果中看头图辨识度）
- 诊断要点：
  - 头图是否有辨识度（专业照vs随手拍）
  - 差异化标识是否突出（24h急诊、专科等）
  - 与周边竞品的视觉对比
- 数据标签：曝光→点击率 本店vs周边vs同城

**要素二：门店名称与标签 → 影响「搜索排名」**
- 截图：门店详情首页
- 诊断要点：
  - 标题与实际服务是否一致（如写24h但营业时间不是24h）
  - 标签覆盖是否全面
  - 搜索量对比
- 数据标签：搜索量 本店vs周边

**要素三：评价与评分 → 影响「信任感/导航率」**
- 截图：评价页面
- 诊断要点：
  - 评价数量是否足够
  - 评价质量和更新时间
  - 与竞品评价对比
- 数据标签：评价数vs竞品到访记录

**要素四：团购与优惠 → 影响「到店动机」**
- 截图：团购页面
- 诊断要点：
  - 有无团购项目
  - 团购价格vs竞品
  - 无团购的影响分析
- 数据标签：本店团购数vs周边

**要素五：营业时间与联系方式 → 影响「来电率/导航率」**
- 截图：营业时间页面
- 诊断要点：
  - 营业时间与标题是否匹配
  - 有无在线预约入口
  - 转化链路是否完整
- **此要素特殊：** 无截图左右布局，使用全宽分析区域 + 内嵌漏斗卡片（`.funnel-inline`）
- 漏斗卡片三联展示：
  ```
  | 曝光→点击 X% | 点击→导航 X% | 点击→来电 X% |
  | 周边 X% · 同城 X% | ... | ... |
  ```

## 七、文案撰写规则

### 7.1 问题描述风格

- **直接、有主见**，不说废话
- **先说结论后说原因**："评价数量严重不足，信任背书缺失" → 具体说明多少条、对比竞品多少
- **数字说话**：每个问题都要带数据对比
- **口语化但专业**：像懂行的人在跟老板说话

### 7.2 数据标签格式

```
{指标名} {本店值} vs 周边 {周边值} vs 同城 {同城值}
```

示例：
- `曝光→点击率 3.2% vs 周边 3.4% vs 同城 4.1%`
- `搜索量 898 vs 周边 22,000 · 差距96%`
- `博雅 0团购 vs 周边门店均有¥154-358团购`
- `评价 12条 vs 周边竞品 190-323人到访记录`

### 7.3 差距标签格式

- 绝对值差距：`仅周边X%`（红色）
- 转化率优势：`高于周边`（绿色）
- 转化率劣势：`略低`（红色）
